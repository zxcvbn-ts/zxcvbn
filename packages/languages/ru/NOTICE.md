This package includes data derived from the OpenSubtitles 2024 dataset via
[OPUS](https://opus.nlpl.eu/datasets/OpenSubtitles) in `src/commonWords.json`.

- Source frequency file: [OpenSubtitles 2024 `ru.freq.gz`](https://object.pouta.csc.fi/OPUS-OpenSubtitles/v2024/freq/ru.freq.gz)
- Provider: Helsinki-NLP / OPUS
- License: [Open Data Commons Attribution License (ODC-BY) 1.0](https://opendatacommons.org/licenses/by/1-0/)

The data in `src/commonWords.json` is a processed derivative: tokenized text,
frequency aggregation, normalization, and filtering. Attribution for the source
dataset is provided here; this package is not endorsed by the dataset providers.

Any redistribution of this package must retain this notice and the ODC-BY
attribution.
